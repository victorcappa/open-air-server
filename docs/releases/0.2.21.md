# Air Server 0.2.21 for Apple Silicon

This release adds a native low-latency video path from Air Server to Resolume.

## Resolume / Syphon output

- Enable **Saída para Resolume (Syphon)** under Settings → Video.
- Connect the iPhone through AirPlay.
- In Resolume, open Sources → Syphon and select **Air Server — iPhone**.
- The normal independent Air Server window remains available at the same time.

The Syphon server runs locally on the Mac. It requires no internet connection
and adds frame conversion work only while a Syphon client is attached. Syphon
transports video only; AirPlay audio continues through the selected macOS audio
output.
