# Air Server 0.2.18 for Apple Silicon

This release adds direct AirPlay between a nearby iPhone and Mac, without a
shared Wi-Fi network or router, and includes the 0.2.17 low-latency renderer
improvements.

## Direct connection

- Advertises AirPlay and RAOP over macOS AWDL in addition to normal Bonjour.
- Accepts receiver sockets from Apple's peer interfaces.
- Shows the first-connection four-digit PIN in the Air Server waiting window.
- Ignores a saved LAN adapter pin on macOS so it cannot block AWDL.
- Reports a clear setup notification when the native macOS AirPlay Receiver
  switch is disabled.

Wi-Fi must remain enabled on both devices, but neither device needs to be joined
to a Wi-Fi network. Enable **AirPlay Receiver** once in System Settings → General
→ AirDrop & Handoff.

Physical off-network iPhone acceptance remains required before using this as the
only show path; keep the shared local-network route as a rehearsed fallback.
