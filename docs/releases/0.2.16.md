# Air Server 0.2.16 for Apple Silicon

This is the first ready-to-install public build of Air Server.

## Included

- Independent AirPlay receiver window on macOS.
- Receiver advertised as `AIR SERVER`.
- Clear waiting screen and menu-bar operation without a Dock icon.
- Portrait and landscape rotation, VideoToolbox decoding and audio playback.
- Projector selection, borderless/fullscreen mode and always-on-top mode.
- Self-contained runtime: no Homebrew, GStreamer, Rust or Terminal setup needed.

## Install

1. Download `Air-Server-0.2.16.dmg` below.
2. Open it and drag **Air Server** to **Applications**.
3. On the first launch, Control-click **Air Server**, choose **Open**, then confirm.
4. On the iPhone, open Control Center, choose Screen Mirroring and select **AIR SERVER**.

The build is ad-hoc signed, not Apple-notarized, and supports Apple Silicon Macs
running macOS 11 or newer.

## Network

Internet access is not required. This version requires the Mac and iPhone to be
on the same local Wi-Fi/LAN. Direct router-free AWDL operation is not enabled in
this release.
