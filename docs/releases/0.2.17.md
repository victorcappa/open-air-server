# Air Server 0.2.17 for Apple Silicon

This release reduces live screen-mirroring delay on macOS.

## Low-latency changes

- Requests 1080p60 instead of UxPlay's automatic 4K profile when H.265 is on.
- Keeps at most one decoded frame waiting at the macOS display sink.
- Reuses IOSurface-backed pixel buffers and the video format description between
  frames instead of allocating both for every frame.
- Flushes stale display work under backpressure so delay cannot keep growing.
- Stops requesting and logging the iPhone's periodic performance plist during
  normal operation.

The renderer was exercised with a physical iPhone at 60 fps and showed no sink
overflow drops. Perceived glass-to-glass latency still needs acceptance on the
actual Wi-Fi/router/projector path used for a show.
