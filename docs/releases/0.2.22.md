# Air Server 0.2.22 for Apple Silicon

This release restores the expected macOS app identity when Settings is open.

## App icon

- Settings now appears in the Dock and Cmd-Tab with the Air Server icon.
- Closing Settings removes that Dock entry; the receiver continues running in
  the menu bar.
- Packaging now treats a missing or invalid application icon as a build error
  instead of silently shipping an iconless bundle.
