# Air Server 0.2.19 for Apple Silicon

This release adds operator-selectable AirPlay video quality on top of the direct
AWDL connection and low-latency renderer introduced in the preceding builds.

## Video controls

- Resolution presets: 720p, 1080p, 1440p and 4K.
- 1080p remains the default balance between definition and latency.
- 720p is available for lower processing and wireless load.
- The selected resolution works alongside the existing maximum FPS, H.265,
  hardware-decoder, fullscreen, display and audio controls.
- Saving a new resolution restarts only the receiver engine so the next AirPlay
  session receives the new profile.

The configuration value is allow-listed before it reaches UxPlay; unknown or
manually corrupted values fall back safely to 1080p.
