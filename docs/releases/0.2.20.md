# Air Server 0.2.20 for Apple Silicon

This release fixes launch feedback and direct AirPlay discovery on current
macOS versions.

## Fixes

- Opening the application now opens Settings immediately.
- Opening the application again while it is already running opens Settings
  instead of appearing to do nothing.
- Direct peer-to-peer AirPlay recognizes the current macOS
  `AirplayReceiverAdvertising` preference when the older
  `AirplayReceiverEnabled` key is absent.
- An explicitly disabled native AirPlay Receiver is still rejected, preserving
  the system prerequisite for AWDL discovery.

The application remains usable without internet, a router, or a shared Wi-Fi
network. Wi-Fi must remain enabled on both devices for the direct AWDL radio
link.
